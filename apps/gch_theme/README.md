## GCH Theme

GCH UI Customizations

### Installation

1. Get app

    `bench get-app gch_theme https://github.com/Gertrude-s-Children-s-Hospital/gch-theme`

2. Install app

    `bench install-app gch_theme`

3. Rebuild Assets

    `bench build`

4. Clear cache

    `bench clear-cache`

5. Restart services

    `bench start`
